About TA Studio Loop.

TA Studio Loop (TASL) is an independent, bootstrapped software project founded in August 2026 by Tuấn Anh Hoàng and developed by YVN Studio in Vietnam. TASL builds AI-native production software for long-form storytelling workflows.

What we build

TASL connects scripting, voice production, scene and prompt planning, media generation, rendering, quality review, and publishing operations. The software is built from a working media-production operation rather than as a standalone demo.

Current products

TA Studio Loop is the core workflow platform. TASL Voice is a Windows voice-production module with a stable public v1.1.2 release.

Production use

TASL is used internally by 6–10 production users across 10+ production machines/workers, with 100+ production jobs processed and 100+ TASL Voice production outputs.
